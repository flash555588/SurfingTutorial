# 虚拟机基础：在一台电脑上运行多个系统

## 什么是虚拟机

虚拟机（Virtual Machine）是在现有操作系统上模拟出的一台"虚拟电脑"，可以安装运行另一个操作系统。

**类比理解：**
```
物理电脑 = 房子
虚拟机 = 房子里的隔间

每个隔间可以住不同的"人"（操作系统）
但共享房子的基础设施（CPU、内存、硬盘）
```

## 为什么要用虚拟机

- **测试软件**：在隔离环境中测试软件，避免影响主机
- **学习 Linux**：不需要单独电脑就能学习 Linux
- **运行旧版 Windows**：兼容老旧软件
- **安全隔离**：访问可疑网站时保护真实系统
- **开发测试**：模拟不同操作系统进行测试

## 主流虚拟机软件

### VirtualBox
- **类型**：免费开源
- **优点**：免费、功能完善、跨平台、对系统版本无要求
- **缺点**：性能相对较低
- **下载地址**：https://www.virtualbox.org/
- **适合系统**：Windows 家庭版/专业版均可

### VMware Workstation Pro
- **类型**：商业软件
- **优点**：性能优秀、功能强大、稳定
- **缺点**：付费
- **下载地址**：https://www.vmware.com/

### VMware Workstation Player
- **类型**：免费个人使用
- **优点**：免费、性能好
- **缺点**：功能比 Pro 版少

### Hyper-V
- **类型**：Windows 内置
- **优点**：系统自带，无需安装
- **缺点**：
  - **仅 Windows 专业版/企业版可用**
  - **Windows 家庭版用户无法使用**
- **下载地址**：Windows 专业版自带，无需下载

> **Windows 家庭版用户注意**：如果你的系统是 Windows 家庭版，Hyper-V 不可用。建议使用 VirtualBox，它是完全免费且功能完善的替代方案。

## 笔记本电脑用户特别说明

### 合盖模式设置

笔记本电脑使用虚拟机时，默认合盖会休眠电脑，导致虚拟机中断。需要修改电源设置：

**Windows 10/11 设置步骤：**

1. 右键点击开始菜单 > **电源选项**
2. 点击右侧 **选择关闭笔记本计算机盖的功能**
3. 将"关闭盖子时"改为：
   - **接通电源**：不采取任何操作
   - **使用电池**：不采取任何操作
4. 点击 **保存修改**

### 电源管理优化

1. 插入电源适配器再使用虚拟机（性能更稳定）
2. 将电源计划调整为 **高性能**：
   - 控制面板 > 电源选项 > 高性能
3. 避免在使用电池时运行大型虚拟机

### 性能分配建议

笔记本电脑散热有限，分配资源要留有余地：

| 笔记本电脑配置 | 分配给虚拟机 | 说明 |
|---------------|-------------|------|
| 8GB 内存 | 2-4 GB | 同时保障主机流畅 |
| 16GB 内存 | 4-8 GB | 可以流畅运行多数系统 |
| 4 核 CPU | 2 核 | 不要超过一半 |

## VirtualBox 安装详细步骤

### 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 支持虚拟化（VT-x/AMD-V） | 4 核以上 |
| 内存 | 4 GB | 16 GB 以上 |
| 硬盘 | 20 GB 可用空间 | SSD 100 GB 以上 |
| 系统 | Windows 任意版本 | 无版本限制 |

### 检查虚拟化是否开启

**第一步：确认 CPU 支持虚拟化**

1. 按 `Win + R`，输入 `msinfo32`，回车
2. 在右侧找到 **处理器** 一栏，查看 CPU 型号
3. 搜索你的 CPU 型号确认是否支持虚拟化技术

**第二步：检查虚拟化是否已启用**

1. 打开任务管理器（`Ctrl + Shift + Esc`）
2. 点击 **性能** 标签
3. 点击左侧 **CPU**
4. 右下角查看 **虚拟化** 项：
   - 显示 **"已启用"** → 虚拟化已开启，可直接安装 VirtualBox
   - 显示 **"已禁用"** → 需要在 BIOS 中开启（见下文）

### 开启 CPU 虚拟化（BIOS 设置）

如果虚拟化显示已禁用，需要在 BIOS/UEFI 中开启。**笔记本电脑各品牌进入 BIOS 的按键不同**：

| 品牌 | 按键 | 备注 |
|------|------|------|
| 联想 | F2 或 Fn + F2 | 部分机型需按 Novo 按钮 |
| 惠普 | F10 或 Esc | 开机时按 Esc 看提示 |
| 戴尔 | F2 或 F12 | 部分机型需先按 F12 再选 BIOS |
| 华硕 | F2 或 Del | 主板型号可能不同 |
| 宏碁 | F2 或 Del | 轻薄本可能需 Fn + F2 |
| 华为 | F2 或 Del | MateBook 系列适用 |
| 小米 | F2 或 Del | 笔记本系列适用 |
| 三星 | F2 或 Del | 笔记本系列适用 |

**BIOS 中开启虚拟化步骤（各品牌略有差异）：**

> [!CAUTION]
> 修改 BIOS 设置有风险，错误修改可能导致系统无法启动。如不确定，请联系电脑厂商客服获取指导。

1. 开机按指定按键进入 BIOS
2. 使用方向键切换到 **Configuration** 或 **Advanced** 或 **Security** 标签
3. 找到 **Virtualization Technology** 或 **Intel VT-x** 或 **AMD-V** 选项
4. 将其设置为 **Enabled**
5. 按 **F10** 保存并退出
6. 电脑会自动重启

> **找不到选项？**
> - 有些笔记本电脑的 BIOS 密码受限于厂商，可能无法修改
> - 部分华为/荣耀笔记本需要在 BIOS 中先关闭"安全启动"才能看到虚拟化选项
> - 如果修改 BIOS 有困难，可以联系电脑厂商客服

### 安装过程

#### 第一步：下载 VirtualBox

1. 访问 https://www.virtualbox.org/wiki/Downloads
2. 点击 "Windows hosts" 下载安装包
3. 下载完成后，双击运行安装程序

#### 第二步：运行安装程序

1. 弹出 "安全警告"，点击 "是"
2. 点击 "Next" 继续
3. 选择安装位置（建议保持默认）
4. 点击 "Next"
5. 弹出警告提示网络连接会中断，点击 "Yes"
6. 点击 "Install" 开始安装
7. 安装过程中会弹出驱动安装提示，点击 "始终安装此驱动程序软件"
8. 完成安装后点击 "Finish"

#### 第三步：验证安装

1. 打开 VirtualBox
2. 点击 "管理" > "全局设定"
3. 确认版本号显示正常
4. 点击 "确定" 关闭

### 创建虚拟机详细步骤

#### 第一步：新建虚拟机

1. 打开 VirtualBox，点击左上角 "新建"
2. 在 "名称" 输入框中输入虚拟机名称（如 "Ubuntu"）
3. 在 "文件夹" 选择虚拟机存放位置（建议放在 D 盘或 SSD 上）
4. 在 "类型" 选择要安装的操作系统（Linux、Windows 等）
5. 在 "版本" 选择具体版本（Ubuntu 64 位、Windows 10 64 位等）
6. 点击 "下一步"

#### 第二步：分配内存

1. 滑动滑块或直接输入分配给虚拟机的内存大小
2. 建议：
   - 2 GB：学习 Linux 基础够用
   - 4 GB：流畅使用图形界面
   - 8 GB：专业使用或运行 Windows
3. **注意：不要超过绿色区域，避免主机卡顿**
4. 点击 "下一步"

#### 第三步：创建虚拟硬盘

1. 选择 "现在创建虚拟硬盘"
2. 点击 "创建"
3. 硬盘文件类型选择 "VDI"（VirtualBox 专用格式）
4. 点击 "下一步"
5. 存储方式：
   - "动态分配"：文件随使用增长，省空间
   - "固定大小"：性能更好，速度快
6. 点击 "下一步"
7. 设置硬盘大小：
   - Ubuntu：建议 25 GB 以上
   - Windows：建议 60 GB 以上
8. 点击 "创建"

### 安装操作系统

#### 第一步：加载 ISO 镜像

1. 在 VirtualBox 主界面选中创建的虚拟机
2. 点击 "启动" 按钮
3. 首次启动会提示选择启动盘，点击文件夹图标
4. 点击 "添加" 按钮
5. 浏览并选择下载好的系统 ISO 文件
6. 选中 ISO，点击 "选择"
7. 点击 "启动"

#### 第二步：安装系统

**Ubuntu 安装示例：**

1. 选择语言（中文或 English），按 Enter
2. 选择 "安装 Ubuntu"
3. 键盘布局保持默认，点击 "继续"
4. 选择 "正常安装"，点击 "继续"
5. 选择 "清除整个磁盘并安装"，点击 "现在安装"，再点击 "继续"
6. 选择时区（上海），点击 "继续"
7. 输入姓名、计算机名、用户名、密码，点击 "继续"
8. 开始安装，等待完成
9. 安装完成后点击 "现在重启"

**Windows 安装示例：**

1. 选择语言和时间格式，点击 "下一步"
2. 点击 "现在安装"
3. 输入产品密钥（或跳过），点击 "下一步"
4. 选择要安装的 Windows 版本，点击 "下一步"
5. 勾选 "我接受许可条款"，点击 "下一步"
6. 选择 "自定义：仅安装 Windows"
7. 选择要安装到的分区，点击 "下一步"
8. 等待安装完成（期间会重启几次）

### 安装增强功能

增强功能可以提升虚拟机使用体验，必须安装。

#### VirtualBox 增强功能安装

1. 虚拟机菜单：设备 > 安装增强功能
2. 如果没有自动运行，在虚拟机中打开光盘驱动器
3. 双击 "VBoxWindowsAdditions.exe"（Windows）或运行 "sudo ./VBoxLinuxAdditions.run"（Linux）
4. 点击 "安装"
5. 安装完成后重启虚拟机

#### 增强功能的作用

| 功能 | 说明 |
|------|------|
| 自动调整分辨率 | 虚拟机窗口缩放时，内容自动适应 |
| 共享文件夹 | 主机和虚拟机之间共享文件 |
| 共享剪贴板 | 复制粘贴互通 |
| 拖放文件 | 直接拖拽传输文件 |
| 鼠标无缝移动 | 鼠标移出虚拟机不再需要按 Host 键 |

## 虚拟机网络设置

### 网络模式详解

| 模式 | 说明 | 虚拟机能否访问外网 | 主机能否访问虚拟机 |
|------|------|-------------------|-------------------|
| NAT | 共享主机 IP | 能 | 不能（需要端口转发） |
| NAT 网络 | 独立 NAT | 能 | 不能 |
| 桥接 | 独立 IP | 能 | 能 |
| 仅主机 | 仅主机可见 | 不能 | 能 |
| 内部网络 | 仅虚拟机间 | 不能 | 不能 |

### 推荐配置

**日常使用（上网、办公）：**
```
网络模式：NAT
```

**需要从外部访问虚拟机（如搭建服务器）：**
```
网络模式：桥接
获取 IP：DHCP 或手动设置
```

**完全隔离（测试危险软件）：**
```
网络模式：仅主机
```

### 端口转发（NAT 模式访问虚拟机）

1. 虚拟机菜单：设备 > 网络 > 网络设置
2. 点击右侧 "+" 添加规则
3. 填写：
   - 名称：Web 服务
   - 协议：TCP
   - 主机端口：8080
   - 子系统端口：80
4. 点击 "确定"

## 快照功能详解

快照可以保存虚拟机的任意状态，随时可以恢复。

### 创建快照

**VirtualBox：**
1. 关闭虚拟机（或暂停）
2. 点击 "快照" 标签
3. 点击相机图标
4. 输入快照名称和描述
5. 点击 "确定"

**VMware：**
1. 点击 "虚拟机" > "快照" > "拍摄快照"
2. 输入名称和描述
3. 点击 "拍摄快照"

### 恢复快照

1. 选中要恢复的快照
2. 点击 "恢复" 按钮
3. 确认恢复操作

### 管理快照

| 操作 | VirtualBox | VMware |
|------|------------|---------|
| 创建 | 快照面板 > 拍摄 | 虚拟机 > 快照 > 拍摄 |
| 恢复 | 选中快照 > 恢复 | 虚拟机 > 快照 > 恢复 |
| 删除 | 选中快照 > 删除 | 虚拟机 > 快照 > 删除 |

## 常见问题与解决方法

### 安装问题

#### Q1：安装 VirtualBox 时提示 "安装失败"

**原因**：之前安装过 VirtualBox 未完全卸载

**解决方法：**
1. 使用 CCleaner 或 Revo Uninstaller 完全卸载
2. 删除以下文件夹：
   - C:\Program Files\Oracle\VirtualBox
   - C:\Users\用户名\.VirtualBox
   - C:\Users\用户名\VirtualBox VMs
3. 重启电脑
4. 重新安装

#### Q2：提示 "CPU 不支持虚拟化"

**原因**：CPU 虚拟化未开启或不支持

**解决方法：**
1. 按 `Win + R`，输入 `msinfo32`，回车
2. 查看 **虚拟化** 是否显示 "已启用"
3. 如果显示 "已禁用"，重启电脑，进入 BIOS 开启
4. 开启后重启再试

#### Q3：64 位选项不可选

**原因**：
- CPU 不支持 64 位
- 未开启 CPU 虚拟化

**解决方法：**
1. 确认 CPU 支持 64 位
2. 在 BIOS 中开启 VT-x/AMD-V
3. 确保未开启 Hyper-V（与 VirtualBox 冲突，Windows 家庭版用户可忽略此项）

#### Q4：Windows 家庭版看不到 Hyper-V 选项

**这是正常的**，Hyper-V 仅在 Windows 专业版/企业版中可用。

**解决方案：**
- 使用 VirtualBox 代替（功能基本一致，完全免费）
- 如果必须使用 Hyper-V，需要重装 Windows 专业版系统

### 运行问题

#### Q5：虚拟机很卡

**原因**：分配资源不足

**解决方法：**
```
1. 增加内存：设置 > 系统 > 主板 > 内存
2. 增加 CPU：设置 > 系统 > 处理器
3. 开启 3D 加速：设置 > 显示 > 屏幕 > 启用 3D 加速
4. 使用固态硬盘存储虚拟机文件
5. 笔记本电脑请插上电源适配器使用
```

#### Q6：虚拟机无法上网

**解决方法（按顺序尝试）：**

**方法 1：检查网络模式**
1. 虚拟机菜单：设备 > 网络 > 网络设置
2. 确认连接方式为 "NAT" 或 "桥接"
3. 点击 "确定"

**方法 2：重启虚拟机网络**
1. 在虚拟机中打开终端（Windows: CMD，Linux: Ctrl+Alt+T）
2. Windows 输入：`ipconfig /release && ipconfig /renew`
3. Linux 输入：`sudo systemctl restart NetworkManager`

**方法 3：重新安装增强功能**
1. 虚拟机菜单：设备 > 增强功能 > 重新安装增强功能
2. 重启虚拟机

#### Q7：鼠标无法移出虚拟机

**原因**：未安装增强功能或安装失败

**解决方法：**
1. 按右 Ctrl 键（Host 键）暂时释放鼠标
2. 安装增强功能：
```
虚拟机菜单：设备 > 安装增强功能
```
3. 安装完成后重启虚拟机

#### Q8：虚拟机分辨率太低

**解决方法：**
1. 安装增强功能
2. 虚拟机菜单：视图 > 自动调整显示尺寸
3. 虚拟机菜单：设备 > 显示 > 调整自动缩放

#### Q9：与主机共享文件失败

**解决方法：**
1. 确认已安装增强功能
2. 虚拟机菜单：设备 > 共享文件夹 > 共享文件夹设置
3. 点击 "+" 添加
4. 选择主机上的文件夹路径
5. 勾选 "自动挂载" 和 "固定挂载"
6. 在虚拟机中访问：Windows 使用网络位置，Linux 使用 /media/sf_文件夹名

#### Q10：合上笔记本盖子后虚拟机断开

**解决方法：**
1. Windows 搜索 "电源选项"
2. 点击 "选择关闭笔记本计算机盖的功能"
3. 将 "关闭盖子时" 改为 "不采取任何操作"
4. 保存修改

#### Q11：虚拟机显示 "未捕获键盘"

**解决方法：**
1. 点击虚拟机窗口
2. 按右 Ctrl 键
3. 虚拟机菜单：机器 > 键盘设置 > 重置

#### Q12：虚拟机没有声音

**解决方法：**
1. 虚拟机菜单：设备 > 声音 > 声音设置
2. 启用音频
3. 选择主机音频驱动

## 性能优化建议

### 1. 硬件分配

| 资源 | 建议 | 说明 |
|------|------|------|
| CPU | 2-4 核 | 不超过主机核心数的一半 |
| 内存 | 2-4 GB | 不要超过主机可用内存的 50% |
| 显存 | 128 MB | 够用即可 |
| 硬盘 | 固定大小 | 性能比动态分配更好 |

### 2. 存储位置

- 将虚拟机文件放在 SSD 上
- 关闭虚拟机后进行碎片整理
- 定期清理不需要的快照

### 3. 笔记本电脑特别优化

- **插电使用**：电源供电更稳定，性能更好
- **高性能模式**：控制面板 > 电源选项 > 高性能
- **散热注意**：长时间运行注意笔记本散热
- **外接鼠标**：减少触控板占用资源

### 4. 虚拟机内部优化

- 关闭不必要的动画效果
- 禁用虚拟机不必要的服务
- 安装轻量级桌面环境（Linux）

## 安全提醒

1. **来源可信**：只安装来源可靠的系统镜像
2. **隔离使用**：可疑文件在虚拟机中打开
3. **定期备份**：创建快照防止数据丢失
4. **资源控制**：不要分配超过主机实际拥有的资源

## 选择建议

| 系统版本 | 推荐工具 |
|----------|----------|
| Windows 家庭版 | VirtualBox（免费，无需版本升级） |
| Windows 专业版 | VirtualBox 或 Hyper-V（均可用） |
| 需要高性能 | VMware Workstation Pro |
| 预算有限 | VirtualBox（免费功能最全） |

> **提示**：VirtualBox 是 Windows 家庭版用户的最佳选择，完全免费且功能完善，无需升级系统即可使用。

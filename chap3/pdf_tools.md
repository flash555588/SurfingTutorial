# PDF 工具指南：处理 PDF 文件

## 什么是 PDF

PDF（Portable Document Format）是一种跨平台的文档格式，由 Adobe 开发，可在不同设备上保持一致的排版效果。

**PDF 的特点：**
- 跨平台兼容
- 排版固定不变
- 支持图文混排
- 支持加密和权限设置

## PDF 合并与拆分

### PDF24 Creator
1. 下载安装 PDF24 Creator
2. 选择"合并 PDF"或"拆分 PDF"
3. 添加文件，调整顺序
4. 执行操作

1. 访问 Smallpdf 或 iLovePDF

## PDF 加密与解密

### 设置密码保护
```
Adobe Acrobat:
1. 打开 PDF 文件
2. 文件 > 另存为 > 受保护的 PDF
3. 设置打开密码和权限密码
```

### 解除密码
- 使用 Adobe Acrobat
- 使用在线工具（如 iLovePDF）
- 注意：仅限自己有权限的 PDF 文件

## 常见问题

### Q1：PDF 打不开怎么办
1. 更新 PDF 阅读器
2. 尝试其他阅读器
3. 检查文件是否损坏

### Q2：PDF 文字无法复制
- 可能是因为 PDF 是扫描件生成的
- 使用 OCR 工具识别文字
- 推荐工具：Adobe Acrobat、在线 OCR

### Q3：PDF 编辑需要收费吗
- 基本阅读：免费
- 编辑功能：多数工具收费
- 在线工具：部分功能免费

### Q4：如何删除 PDF 中的敏感信息
- 使用 Adobe Acrobat 墨水编辑功能
- 使用 PDF24 的删除功能
- 彻底删除需要重新生成 PDF

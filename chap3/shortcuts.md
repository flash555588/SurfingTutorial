# 快捷键：这些按键组合能让你快到飞起

## 为什么你要学快捷键

用鼠标点一下平均要 1-2 秒，快捷键只要 0.1 秒。听起来不多？但你每天点几百次，累积下来就吓人了。

* 想象一下：写代码时不用鼠标就能全文跳转
* 写文档时双手不用离开键盘一直摸鼠标
* 玩游戏时手速快到队友以为你开挂了（并没有）

**学快捷键不是死记硬背，是在遇到重复操作时问一下自己"有没有快捷键"，然后记住它。**

## Windows 系统快捷键

### 你必须记住的（真的必须）

* `Win` - 打开开始菜单
* `Win + D` - 马上显示桌面（按多几次你就离不开了）
* `Win + E` - 打开我的电脑
* `Win + L` - 锁屏（离开工位时记得按一下）
* `Alt + Tab` - 切换窗口
* `Alt + F4` - 关掉当前窗口
* `Ctrl + Shift + Esc` - 打开任务管理器
* `Print Screen` - 全屏截图
* `Win + Shift + S` - 区域截图（比全屏更实用）

### 窗口管理（分屏必备）

* `Win + ←` - 窗口贴左边
* `Win + →` - 窗口贴右边
* `Win + ↑` - 最大化
* `Win + ↓` - 最小化
* `Win + ↑`（已最大化时）- 还原窗口
* `Win + Tab` - 打开任务视图
* `Alt + Tab` - 切换应用

### 文件资源管理器

* `Win + E` - 打开此电脑
* `Ctrl + N` - 新开窗口
* `Ctrl + W` - 关掉当前窗口
* `Ctrl + 鼠标滚轮` - 调整图标大小
* `Home` - 跳到开头
* `End` - 跳到末尾
* `Delete` - 删掉文件（进回收站）
* `Shift + Delete` - 直接删掉（不经过回收站）
* `F2` - 重命名（超常用）
* `F5` - 刷新
* `Ctrl + Shift + N` - 新建文件夹

### 文本编辑（最实用）

* `Ctrl + C` - 复制
* `Ctrl + V` - 粘贴
* `Ctrl + X` - 剪切
* `Ctrl + Z` - 撤销（写错字了就按它）
* `Ctrl + Y` - 重做
* `Ctrl + A` - 全选
* `Ctrl + S` - 保存（养成习惯按这个）
* `Ctrl + F` - 查找
* `Ctrl + H` - 替换
* `Delete` - 删光标后面的字
* `Backspace` - 删光标前面的字（退格键）

### 进阶操作

* `Win + R` - 打开运行窗口（输命令用的）
* `Win + X` - 打开开始菜单的隐藏功能列表
* `Win + A` - 打开通知中心
* `Win + P` - 投影设置（接显示器时用）
* `Ctrl + Shift + 1/2/3` - 切换输入法

## 浏览器快捷键

### 标签页操作

* `Ctrl + T` - 新建标签页
* `Ctrl + W` - 关掉当前标签页
* `Ctrl + Shift + T` - 恢复刚关掉的标签页（手滑关了有用的页面就靠它）
* `Ctrl + Tab` - 下一个标签页
* `Ctrl + Shift + Tab` - 上一个标签页
* `Ctrl + 1-8` - 直接跳到第 N 个标签页
* `Ctrl + 9` - 跳到最后一个标签页

### 地址栏和页面

* `Ctrl + L` - 选中地址栏
* `Ctrl + Enter` - 自动加上 .com
* `Ctrl + D` - 收藏当前页面
* `Ctrl + Shift + B` - 显示/隐藏书签栏
* `Ctrl + H` - 打开历史记录
* `Ctrl + J` - 打开下载列表
* `F5` - 刷新页面
* `Ctrl + Shift + Delete` - 清除浏览数据
* `Ctrl + Shift + N` - 新建隐身窗口
* `F11` - 全屏模式

## CMD / PowerShell 快捷键

### 通用（terminal 都能用）

* `↑ / ↓` - 翻历史命令
* `Tab` - 自动补全（输路径时特别有用）
* `Ctrl + C` - 取消当前命令
* `Ctrl + L` - 清屏
* `Esc` - 清空当前输入
* `Home` - 光标跳到行首
* `End` - 光标跳到行尾
* `Ctrl + Home` - 删到行首
* `Ctrl + End` - 删到行尾

### CMD 专属

* `F7` - 显示命令历史（很有意思的功能）
* `F9` - 按编号选择命令

### PowerShell 专属

* `Ctrl + R` - 搜索历史命令
* `Ctrl + S` - 暂停输出
* `Ctrl + Break` - 强制中断

## 怎么学快捷键最有效

### 1. 循序渐进

先记住最常用的 10 个左右就够了：
`Ctrl + C/V/Z/S/F`，`Win + D/L/E`，`Alt + Tab`，`F2`

其他的用到的时候再查，用多了自然就记住了。

### 2. 刻意练习

遇到重复操作就停下来想一下"有没有快捷键"。比如你要切换窗口，别去点鼠标了，用 `Alt + Tab`。一开始会慢，坚持一周就习惯了。

### 3. 善用提示

* 菜单里通常会显示快捷键
* 很多软件快捷键都写在功能旁边
* 记不住的写个小纸条放显示器旁边

---

> **提示**：快捷键真的不需要死记硬背。在日常使用中遇到重复操作时，**停一下想一想"有没有快捷键"**，这样学得最快。

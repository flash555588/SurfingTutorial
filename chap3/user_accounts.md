# 用户账户与锁屏密码：系统安全基础

## Windows账户类型

### 账户类型对比

| 类型 | 说明 | 权限 | 适用场景 |
|------|------|------|----------|
| **管理员账户** | 完全控制权 | 可安装软件、修改系统设置 | 日常使用（不推荐） |
| **标准用户** | 受限操作 | 只能使用已安装软件、不能修改系统 | 日常使用（推荐） |
| **来宾账户** | 临时访问 | 仅能使用部分功能 | 借用电脑给他人 |

### 查看当前账户类型
```
方法1：设置
设置 > 账户 > 你的信息
显示当前账户类型

方法2：命令提示符
net user 用户名
查看"本地组成员"中的"Administrators"
```

## 创建和管理账户

### 创建新账户
```
步骤：
1. 设置 > 账户 > 家庭和其他用户
2. 点击"添加账户"
3. 选择"我没有这个人的登录信息"
4. 选择"添加没有Microsoft账户的用户"
5. 输入用户名、密码
6. 完成创建
```

### 更改账户类型
```
步骤：
1. 设置 > 账户 > 家庭和其他用户
2. 选择要更改的账户
3. 点击"更改账户类型"
4. 选择管理员或标准用户
5. 确认更改
```

### 删除账户

> [!WARNING]
> 删除账户会永久删除该用户的所有文件（桌面、文档、下载等）。请在删除前确保已备份重要数据，或选择"保留文件"选项。

**操作步骤：**
1. 设置 > 账户 > 家庭和其他用户
2. 选择要删除的账户
3. 点击"删除"
4. **重要**：选择"保留文件"（推荐）或"删除账户和数据"
5. 确认删除

**安全建议：**
- 优先选择"保留文件"，确保数据安全
- 确认该账户不再需要后再删除

## 锁屏密码设置

### 设置开机密码
```
步骤：
1. 设置 > 账户 > 登录选项
2. 点击"密码"
3. 点击"添加"
4. 输入新密码、密码提示
5. 点击"下一步"完成
```

### 更改密码
```
方法1：设置
设置 > 账户 > 登录选项 > 密码 > 更改

方法2：Ctrl + Alt + Delete
1. 按 Ctrl + Alt + Delete
2. 选择"更改密码"
3. 输入旧密码和新密码

方法3：命令提示符（管理员）
net user 用户名 新密码
```

### 锁屏方式
| 方式 | 图标 | 操作 |
|------|------|------|
| 快捷键 | | `Win + L` |
| 快捷方式 | | 桌面创建快捷方式：rundll32.exe user32.dll,LockWorkStation |
| 自动锁屏 | ![Settings](../img/favicon_edge.ico) | 设置 > 个性化 > 锁屏界面 > 屏幕超时设置 |

### 登录选项

**Windows Hello（生物识别）：**
```
设置 > 账户 > 登录选项 > Windows Hello
- 指纹识别（需硬件支持）
- 面部识别（需摄像头支持）
- PIN码（推荐设置）
```

**PIN码设置：**
```
优点：
- 比密码更快速方便
- 仅与当前设备绑定，不能直接替代账户密码在其他设备上使用
- 可配合 TPM 等硬件保护，多次输错通常会触发限制或锁定

步骤：
设置 > 账户 > 登录选项 > Windows Hello PIN > 添加
```

**动态锁：**
```
功能：携带配对手机离开时自动锁屏

设置 > 账户 > 登录选项 > 动态锁
勾选"允许Windows在你离开时自动锁定设备"
```

## 家长控制

### 设置家庭账户
```
步骤：
1. 设置 > 账户 > 家庭和其他用户
2. 点击"添加家庭成员"
3. 选择"添加家庭成员"
4. 输入孩子的微软账户或创建新账户
5. 按照指引完成设置
```

### 家长控制功能
| 功能 | 说明 |
|------|------|
| **时间限制** | 设置可使用电脑的时段和时长 |
| **应用限制** | 限制可使用的应用程序 |
| **游戏限制** | 按年龄分级限制游戏 |
| **网站过滤** | 屏蔽不适宜的网站 |
| **活动报告** | 查看孩子的电脑使用情况 |

### 查看活动报告
```
1. 访问 account.microsoft.com/family
2. 登录管理员账户
3. 选择孩子的账户
4. 查看屏幕使用时间、应用使用情况、网站浏览历史
```

## 文件夹权限管理

### 查看文件权限
```
步骤：
1. 右键文件或文件夹
2. 选择"属性"
3. 点击"安全"标签
4. 查看"组或用户名"下的用户列表
5. 点击用户名查看具体权限
```

### 修改文件权限

> [!CAUTION]
> 修改系统文件或程序文件夹的权限可能导致程序无法运行或系统不稳定。谨慎修改 C:\Windows、C:\Program Files 等系统目录的权限。

```
步骤：
1. 右键文件或文件夹 > "属性"
2. 点击"安全"标签
3. 点击"编辑"按钮
4. 选择用户 > 勾选允许的权限
5. 点击确定

注意：更改系统文件权限可能导致问题
```

### 常用权限类型
| 权限 | 说明 |
|------|------|
| **读取** | 查看文件和内容 |
| **写入** | 修改文件 |
| **读取和执行** | 运行程序 |
| **修改** | 读取、写入、删除 |
| **完全控制** | 所有操作 |

## 管理员权限使用

### 何时使用管理员权限
- 安装和卸载软件
- 修改系统设置
- 访问系统保护文件
- 运行某些需要管理员的程序

### 安全使用建议
```
1. 日常使用标准用户账户
2. 仅在需要时临时提升权限
3. 不在管理员账户下浏览网页
4. 警惕UAC提示，不随意点击"是"
```

### UAC（用户账户控制）
```
设置 > 用户账户 > 用户账户控制

四个等级：
- 始终通知
- 仅在应用试图更改时通知（默认）
- 仅在应用试图更改时通知，不降低桌面亮度
- 从不通知

推荐：保持默认设置"仅在应用试图更改时通知"
```

## 密码安全

### 强密码建议
```
建议：
- 长度至少12位
- 包含大小写字母、数字、特殊字符
- 不要使用个人信息（生日、姓名）
- 不要使用常见单词
- 不同网站使用不同密码

示例：
- 弱：password123
- 强：Mk#9fL$vN2@qR
- 更好：选择一个易记的句子，取首字母和特殊字符
```

## 账户问题解决

### 忘记密码

**方法1：Microsoft账户**
```
1. 在另一设备访问 account.live.com/password/reset
2. 通过邮箱或手机验证重置密码
3. 使用新密码登录
```

**方法2：本地账户（以前版本Windows）**
```
注意：需要创建过密码重置磁盘

1. 使用密码重置磁盘
2. 或重装系统
3. 或使用PE系统清除密码
```

### 账户被锁定
```
原因：多次输入错误密码
解决：
- 等待自动解锁（通常15-30分钟）
- 使用管理员账户解锁
- 使用Microsoft账户在线解锁
```

### 无法登录
| 症状 | 可能原因 | 解决方法 |
|------|----------|----------|
| 密码正确但无法登录 | 键盘布局不同 | 检查大小写和键盘语言 |
| 显示"账户已禁用" | 被管理员禁用 | 使用管理员账户启用 |
| 显示"账户已锁定" | 密码错误多次 | 等待或重置密码 |

## 安全建议

### 账户安全 checklist
```
[ ] 设置强密码
[ ] 启用Windows Hello（指纹/PIN）
[ ] 开启动态锁
[ ] 定期更改密码
[ ] 不在公用电脑上保存密码
[ ] 为管理员账户设置不同于标准用户的密码
[ ] 启用账户锁定策略
```

### 防止账户被入侵
```
1. 不点击可疑邮件中的链接
2. 不在陌生网站输入密码
3. 启用两步验证
4. 定期检查账户活动
5. 保持系统和杀毒软件更新
```

# Windows 网络设置：连接与配置

## 网络基础知识

### 网络连接类型

| 类型 | 说明 | 常见场景 |
|------|------|----------|
| **有线连接 (Ethernet)** | 通过网线连接，稳定可靠 | 台式电脑、办公室 |
| **无线连接 (Wi-Fi)** | 通过无线信号连接，方便灵活 | 笔记本、手机、平板 |
| **移动网络** | 通过移动运营商网络 | 无Wi-Fi时的应急上网 |

### 常见网络术语

| 术语 | 解释 |
|------|------|
| **IP地址** | 设备的网络身份标识，如 `192.168.1.100` |
| **子网掩码** | 区分网络地址和主机地址，如 `255.255.255.0` |
| **默认网关** | 访问外网的出口，通常是路由器地址 |
| **DNS** | 域名解析服务器，将域名转换为IP地址 |
| **DHCP** | 自动分配IP地址的协议 |

## 图形界面配置

### 查看网络状态

1. **任务栏网络图标**：
   * 点击右下角网络图标
   * 显示已连接网络、信号强度
   * 可快速切换 Wi-Fi、开启飞行模式

2. **网络和共享中心**：
   * `Win + R` 输入 `ncpa.cpl` 回车
   * 查看所有网络连接
   * 右键可更改适配器选项

### 常见配置操作

#### 1. 忘记/重新连接 Wi-Fi
```
步骤：
1. 点击网络图标
2. 右键点击已连接的Wi-Fi
3. 选择"忘记"
4. 重新搜索并连接
```

#### 2. 手动设置IP地址
```
适用于：网络需要静态IP的场景（如部分企业网络）

步骤：
1. 打开"网络和共享中心"
2. 点击当前连接 > "属性"
3. 双击"Internet协议版本4(TCP/IPv4)"
4. 选择"使用下面的IP地址"
5. 输入IP、子网掩码、网关、DNS
```

#### 3. 刷新 DNS 缓存
```
步骤：
1. 打开命令提示符（管理员）
2. 运行：ipconfig /flushdns
3. 看到"成功刷新DNS解析缓存"即成功

适用场景：访问网站提示DNS错误、域名解析异常
```

#### 4. 重置网络适配器

> [!CAUTION]
> 网络重置会移除并重新安装所有网络适配器，可能导致网络配置丢失（如静态IP、VPN等）。操作前请记录重要网络设置。

```
步骤：
1. 打开"设置" > "网络和Internet"
2. 向下滚动，点击"高级网络设置"
3. 点击"网络重置"
4. 确认重置

适用场景：网络频繁断连、无法连接网络
```

## 常用网络命令

### 命令提示符基础

**打开方式：**
* `Win + R` 输入 `cmd`
* 右键开始菜单 > "终端(管理员)" 或 "命令提示符(管理员)"

### 核心命令速查

| 命令 | 作用 | 示例 |
|------|------|------|
| `ipconfig` | 查看IP配置 | `ipconfig /all` 查看详细信息 |
| `ipconfig /release` | 释放当前IP | 重新获取IP前使用 |
| `ipconfig /renew` | 重新获取IP | 解决IP冲突 |
| `ipconfig /flushdns` | 刷新DNS缓存 | 域名解析问题时使用 |
| `ping <地址>` | 测试连通性 | `ping www.baidu.com` |
| `tracert <地址>` | 追踪路由 | 查看数据包经过的节点 |
| `netstat -an` | 查看端口状态 | 查看网络连接 |
| `nslookup <域名>` | 查询DNS | 检查域名解析 |

### 实用案例

**案例1：诊断网络是否正常**
```cmd
ping www.baidu.com
```
* **成功**：显示Reply from xxx.xxx.xxx.xxx，时间<100ms
* **失败**：显示Request timed out

**案例2：查看详细IP配置**
```cmd
ipconfig /all
```
会显示：MAC地址、IP地址、子网掩码、网关、DNS服务器等

**案例3：测试DNS解析**
```cmd
nslookup www.google.com
```
查看DNS解析返回的IP地址

**案例4：查看端口占用**
```cmd
netstat -ano | findstr :8080
```
查找占用8080端口的进程（最后一列是PID）

## 网络故障排查

### 排查流程图
```
1. 检查物理连接
   └─ 网线是否插好 / Wi-Fi是否开启
         │
2. 检查能否访问网关
   └─ ping 192.168.1.1（网关地址）
         │
3. 检查能否访问外网
   └─ ping 8.8.8.8（Google DNS）
         │
4. 检查DNS解析
   └─ ping www.baidu.com
         │
5. 检查浏览器设置
   └─ 代理服务器设置、扩展冲突
```

### 常见问题与解决

| 问题 | 可能原因 | 解决方法 |
|------|----------|----------|
| 能上QQ但打不开网页 | DNS问题 | 刷新DNS缓存或更换DNS服务器 |
| IP冲突 | DHCP分配重复 | 释放并重新获取IP |
| 网络受限 | DHCP未获取成功 | 手动设置IP或重置网络 |
| Wi-Fi频繁断连 | 驱动问题或信号弱 | 更新驱动或靠近路由器 |

## 网络安全建议

### 公共Wi-Fi安全
* 避免在公共Wi-Fi下进行敏感操作（网银、支付）
* 不连接无密码的陌生Wi-Fi
* 使用VPN加密流量

### 路由器安全
* 修改默认管理员密码
* 启用WPA3或WPA2加密
* 关闭WPS功能
* 定期更新路由器固件

### 防火墙设置
* Windows防火墙保持开启
* 不随意关闭系统防火墙
* 除非必要，不开放端口

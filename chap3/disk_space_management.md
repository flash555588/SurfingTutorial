# 硬盘空间管理：保持C盘健康

## 为什么C盘空间总是不够

其实不是C盘的问题，是你装东西的时候没注意。Windows自己会占掉一大块，剩下的又被各种软件、游戏、下载占满...所以要定期打理一下。

### C盘常见占用来源

* **Windows系统文件** - 这货本身就20-30GB，躲不掉的
* **休眠文件** - 内存多大它就多大，可以关掉
* **虚拟内存** - 内存的后备队，可以搬走
* **系统还原点** - 历史快照，能删旧的去掉
* **Windows更新** - 更新完的缓存，能清
* **临时文件** - 程序运行产生的垃圾，能清
* **应用程序** - 默认装C盘，能搬
* **用户文件** - 桌面、下载、文档，能搬

## 推荐方法：安全清理（这些都没风险）

### 1. 磁盘清理工具（最推荐）

Windows自带的安全清理方式。

**操作步骤：**
1. 打开"此电脑"
2. C盘右键 > "属性"
3. 点"磁盘清理"按钮
4. 勾选要删的类型
5. 点"确定" > "删除文件"

**能清掉这些：**
* 临时文件
* 下载文件夹（可能不想删，看情况）
* 回收站
* 系统日志
* 缩略图缓存
* Windows更新清理（这个可以勾上）

### 2. 手动清理临时文件

**操作步骤：**
1. `Win + R` 输入 `%temp%` 回车
2. `Ctrl + A` 全选
3. `Delete` 删掉
4. 删不掉的就跳过（被占用了）

**优点：** 绝对安全，删的都是临时文件

### 3. 迁移用户文件夹到D盘

把桌面、下载、文档这些移到D盘，C盘就轻松了。

**能搬的文件夹：**
```
桌面        → D:\Users\桌面
下载        → D:\Users\下载
文档        → D:\Users\文档
图片        → D:\Users\图片
音乐        → D:\Users\音乐
视频        → D:\Users\视频
```

**迁移方法：**
1. 打开文件资源管理器
2. 右键要搬的文件夹 > "属性"
3. 点"位置"标签
4. 点"移动"按钮
5. 选择新位置（比如 D:\Users\下载）
6. 确认移动，等完成

**优点：** 治本，不影响程序运行

### 4. 更改软件安装路径

以后装软件注意一下，别一股脑装C盘。

**方法：安装时选自定义路径**
* 点"浏览"，选 D:\Program Files\ 或 D:\Software\
* 看到 C:\Program Files\ 记得改掉

### 5. 清理不需要的程序

**操作步骤：**
1. `Win + I` 打开设置 > 应用
2. 看看列表里有哪些不用的
3. 点卸载
4. 游戏之类的大软件考虑重新装到D盘

### 6. 清理大文件

不知道什么东西占空间？用工具扫一下。

**WizTree（推荐）：**
* 下载：https://www.antibody.com/wiztree/
* 扫描超快，一目了然，知道钱花在哪儿了

**SpaceSniffer：**
* 下载：http://www.uderzo.it/main_products/space_sniffer/
* 可视化显示空间占用

## 高级清理：有点风险的操作

> 以下操作有风险或会影响系统功能，请仔细阅读后再决定是否执行。

### 清理休眠文件

> [!CAUTION]
> 关闭休眠后，快速启动功能也会关闭。如需恢复，运行 `powercfg /hibernate on`。

**关闭休眠（删除hiberfil.sys）：**
```cmd
powercfg /hibernate off
```
* 能释放约等于你内存大小的空间（比如16GB内存 = 16GB空间）
* 休眠功能就用不了了

**开启休眠：**
```cmd
powercfg /hibernate on
```

### 清理系统还原点

> [!WARNING]
> 删除旧还原点后，将无法恢复到删除前的状态。请确认近期系统稳定不需要还原再操作。

**操作步骤：**
1. 右键"此电脑" > "属性"
2. 点击"系统保护"
3. 选择C盘，点击"配置"
4. 将"最大使用量"滑块调低（建议5-10%）
5. 点击确定

**提示：** 可以保留最近1-2个还原点，不必完全删除

### 清理Windows更新缓存

> [!WARNING]
> 清理更新缓存后，将无法卸载已安装的Windows更新。如遇问题，只能通过系统重装解决。

**图形界面操作（安全）：**
1. 设置 > Windows更新 > 高级选项 > 传递优化
2. 关闭"允许从其他电脑下载"

**命令行操作（有风险，需管理员）：**
```cmd
Dism.exe /online /Cleanup-Image /StartComponentCleanup /ResetBase
```

## 虚拟内存管理

> [!CAUTION]
> 修改虚拟内存设置后需要重启电脑。错误设置可能导致系统不稳定。

### 推荐配置

| 内存大小 | 虚拟内存建议 |
|----------|--------------|
| 8GB | 4-8GB |
| 16GB | 2-4GB |
| 32GB+ | 1-2GB或关闭 |

### 转移到其他分区

**操作步骤：**
1. `Win + R` 输入 `sysdm.cpl`
2. 点"高级"标签 > "性能"设置
3. 点"高级"标签 > "更改"
4. 取消"自动管理所有驱动器的分页文件大小"
5. 选择C盘 > "无分页文件" > "设置"
6. 选择其他盘 > "系统管理的大小"
7. 依次点确定，重启电脑

## 注册表修改（高级）

> [!WARNING]
> 修改注册表有风险，错误修改可能导致系统无法启动。优先使用前面的推荐方法。

### 更改默认安装路径

```
路径：HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion

修改：ProgramFilesDir（64位）
     ProgramFilesDir (x86)（32位）
```

**建议：** 仅在前面方法无法满足需求时使用

## 一键清理脚本

> [!CAUTION]
> 运行来历不明的脚本存在安全风险。请确保脚本来源可靠，或在运行前仔细审查脚本内容。

```powershell
# 保存为 clean_disk.ps1 并以管理员运行

Write-Host "开始清理..." -ForegroundColor Green

# 1. 清空回收站
Clear-RecycleBin -Force -ErrorAction SilentlyContinue
Write-Host "[OK] 回收站已清空"

# 2. 清理临时文件夹
Remove-Item -Path "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item -Path "C:\Windows\Temp\*" -Recurse -Force -ErrorAction SilentlyContinue
Write-Host "[OK] 临时文件已清理"

Write-Host "清理完成！" -ForegroundColor Green
Write-Host "建议重启电脑使部分更改生效"
```

## 预防措施

### 分区规划
```
建议分区方案（500GB SSD）：
- C盘：150GB  (系统和软件)
- D盘：350GB  (数据和游戏)

优点：
- 系统崩溃可重装，不影响数据
- 保持C盘有足够剩余空间
```

### 良好习惯
* 安装软件到D盘
* 下载文件保存到D盘
* 桌面不要放太多文件
* 定期运行磁盘清理

### 定期维护
| 频率 | 操作 |
|------|------|
| 每周 | 清空下载文件夹 |
| 每月 | 运行磁盘清理 |
| 每季度 | 检查大文件、清理不用的软件 |

## 常见问题

| 问题 | 解决方法 |
|------|----------|
| C盘变红（空间不足） | 使用磁盘清理、删除临时文件 |
| 无法删除的文件 | 结束相关进程或重启后再删 |
| 清理后空间没变 | 检查是否移动了文件而非删除 |
| 系统变慢 | 可能是虚拟内存或磁盘碎片 |

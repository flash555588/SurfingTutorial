# 硬盘空间管理：保持C盘健康

## 为什么C盘空间总是不够

### C盘常见占用来源

| 来源 | 说明 | 建议 |
|------|------|------|
| Windows系统文件 | 系统核心文件 | 保持20-30GB |
| 休眠文件 | 内存镜像（可关闭） | 可关闭节省空间 |
| 虚拟内存 | 内存的"后备" | 可转移 |
| 系统还原点 | 历史版本快照 | 可清理旧还原点 |
| Windows更新 | 更新文件缓存 | 可定期清理 |
| 临时文件 | 程序运行产生 | 可清理 |
| 应用程序 | 默认安装位置 | 可迁移到D盘 |
| 用户文件 | 文档、下载等 | 可迁移到D盘 |

## 推荐方法：安全清理

### 1. 磁盘清理工具（推荐）

使用 Windows 自带的磁盘清理工具，安全无风险。

**操作步骤：**
1. 打开"此电脑"
2. 右键C盘 > "属性"
3. 点击"磁盘清理"按钮
4. 选择要删除的文件类型
5. 点击"确定" > "删除文件"

**可清理内容：**
- 临时文件
- 下载文件
- 回收站
- 系统日志文件
- 缩略图缓存
- Windows更新清理（可选）

### 2. 手动清理临时文件

**操作步骤：**
1. Win + R 输入 `%temp%` 回车
2. 全选文件（Ctrl + A）
3. 删除（Delete）
4. 跳过无法删除的文件（被占用）

**优点：** 无风险，清理的是临时文件

### 3. 迁移用户文件夹到D盘

把桌面、下载、文档等移动到D盘，释放C盘空间。

**可迁移的文件夹：**
```
桌面        → D:\Users\桌面
下载        → D:\Users\下载
文档        → D:\Users\文档
图片        → D:\Users\图片
音乐        → D:\Users\音乐
视频        → D:\Users\视频
```

**迁移方法：**
1. 打开文件资源管理器
2. 右键要迁移的文件夹 > "属性"
3. 点击"位置"标签
4. 点击"移动"按钮
5. 选择新位置（如 D:\Users\下载）
6. 确认移动

**优点：** 彻底解决C盘空间不足，不影响程序运行

### 4. 更改软件安装路径

安装新软件时，选择安装到D盘。

**方法：安装时选择自定义路径**
- 安装界面中选择"浏览"
- 选择 D:\Program Files\ 或 D:\Software\
- 避免安装到 C:\Program Files\

### 5. 清理不需要的程序

**操作步骤：**
1. Win + I 打开设置 > 应用
2. 查看已安装的应用列表
3. 卸载不常用的软件
4. 游戏等大软件考虑重新安装到D盘

### 6. 清理大文件

使用工具查找占用空间多的大文件，按需清理。

**WizTree（推荐）：**
- 下载：https://wwwantibody.com/wiztree/
- 扫描速度快，一目了然

**SpaceSniffer：**
- 下载：http://www.uderzo.it/main_products/space_sniffer/
- 可视化显示空间占用

## 高级清理：风险操作

> 以下操作有风险或会影响系统功能，请仔细阅读后再决定是否执行。

### 清理休眠文件

> [!CAUTION]
> 关闭休眠功能后，快速启动功能也会关闭。如需恢复，运行 `powercfg /hibernate on`。

**关闭休眠（删除hiberfil.sys）：**
```cmd
powercfg /hibernate off
```
- 释放约等于内存大小的空间（如16GB内存 = 16GB空间）
- 休眠功能将不可用

**开启休眠：**
```cmd
powercfg /hibernate on
```

### 清理系统还原点

> [!WARNING]
> 删除旧还原点后，将无法通过系统还恢复到删除前的状态。请确认近期系统稳定不需要还原再操作。

**操作步骤：**
1. 右键"此电脑" > "属性"
2. 点击"系统保护"
3. 选择C盘，点击"配置"
4. 将"最大使用量"滑块调低（建议5-10%）
5. 点击确定

**提示：** 可以保留最近1-2个还原点，不必完全删除

### 清理Windows更新缓存

> [!WARNING]
> 清理更新缓存后，将无法卸载已安装的Windows更新。如遇问题，只能通过系统重装解决。

**图形界面操作（安全）：**
1. 设置 > Windows更新 > 高级选项 > 传递优化
2. 关闭"允许从其他电脑下载"

**命令行操作（有风险，需管理员）：**
```cmd
Dism.exe /online /Cleanup-Image /StartComponentCleanup /ResetBase
```

## 虚拟内存管理

> [!CAUTION]
> 修改虚拟内存设置后需要重启电脑。错误设置可能导致系统不稳定。

### 推荐配置

| 内存大小 | 虚拟内存建议 |
|----------|--------------|
| 8GB | 4-8GB |
| 16GB | 2-4GB |
| 32GB+ | 1-2GB或关闭 |

### 转移到其他分区

**操作步骤：**
1. Win + R 输入 `sysdm.cpl`
2. 点击"高级"标签 > "性能"设置
3. 点击"高级"标签 > "更改"
4. 取消"自动管理所有驱动器的分页文件大小"
5. 选择C盘 > "无分页文件" > "设置"
6. 选择其他盘 > "系统管理的大小"
7. 依次点击确定，重启电脑

## 注册表修改（高级）

> [!WARNING]
> 修改注册表有风险，错误修改可能导致系统无法启动。优先使用前面的推荐方法。

### 更改默认安装路径

```
路径：HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion

修改：ProgramFilesDir（64位）
     ProgramFilesDir (x86)（32位）
```

**建议：** 仅在前面方法无法满足需求时使用

## 一键清理脚本

> [!CAUTION]
> 运行来历不明的脚本存在安全风险。请确保脚本来源可靠，或在运行前仔细审查脚本内容。

```powershell
# 保存为 clean_disk.ps1 并以管理员运行

Write-Host "开始清理..." -ForegroundColor Green

# 1. 清空回收站
Clear-RecycleBin -Force -ErrorAction SilentlyContinue
Write-Host "[OK] 回收站已清空"

# 2. 清理临时文件夹
Remove-Item -Path "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item -Path "C:\Windows\Temp\*" -Recurse -Force -ErrorAction SilentlyContinue
Write-Host "[OK] 临时文件已清理"

Write-Host "清理完成！" -ForegroundColor Green
Write-Host "建议重启电脑使部分更改生效"
```

## 预防措施

### 分区规划
```
建议分区方案（500GB SSD）：
- C盘：150GB  (系统和软件)
- D盘：350GB  (数据和游戏)

优点：
- 系统崩溃可重装，不影响数据
- 保持C盘有足够剩余空间
```

### 良好习惯
- 安装软件到D盘
- 下载文件保存到D盘
- 桌面不要放太多文件
- 定期运行磁盘清理

### 定期维护
| 频率 | 操作 |
|------|------|
| 每周 | 清空下载文件夹 |
| 每月 | 运行磁盘清理 |
| 每季度 | 检查大文件、清理不用的软件 |

## 常见问题

| 问题 | 解决方法 |
|------|----------|
| C盘变红（空间不足） | 使用磁盘清理、删除临时文件 |
| 无法删除的文件 | 结束相关进程或重启后再删 |
| 清理后空间没变 | 检查是否移动了文件而非删除 |
| 系统变慢 | 可能是虚拟内存或磁盘碎片 |

# Windows 硬盘分区

## 基本概念

### 什么是分区

分区是将一块硬盘划分为多个逻辑存储区域的操作，每个分区可以独立使用。

**常见分区方案：**
```
500GB SSD 分区示例：
- C盘：150GB  (系统+常用软件)
- D盘：350GB  (数据+游戏)
```

### 分区类型

| 类型 | 说明 |
|------|------|
| **主分区** | 可以安装操作系统的分区，最多4个 |
| **扩展分区** | 用于划分子分区，可包含多个逻辑驱动器 |
| **逻辑分区** | 扩展分区内的分区，如D盘、E盘 |

## 磁盘管理工具

> [!WARNING]
> 磁盘分区、格式化等操作会导致数据永久丢失。在进行任何分区操作前，请务必备份重要数据到外部存储设备。

### 打开磁盘管理

**方法1：计算机管理**
1. 右键"此电脑" > "管理"
2. 点击左侧"磁盘管理"

**方法2：快捷命令**
1. Win + R 输入 `diskmgmt.msc`
2. 回车打开

**Windows 11 技巧：**
- Win + X 或 Shift + 右键，点击"磁盘管理"

### 磁盘管理可以做什么

| 操作 | 说明 | 风险 |
|------|------|------|
| 查看磁盘状态 | 查看各分区大小、文件系统 | 无 |
| 压缩卷 | 从现有分区中分离空间 | 低 |
| 扩展卷 | 将自由空间合并到分区 | 低 |
| 格式化 | 清除分区数据 | 高 |
| 删除卷 | 删除整个分区 | 高 |

## 常见操作

### 压缩卷（推荐）

当C盘空间不足时，可以从其他分区压缩出空间。

**操作步骤：**
1. 打开磁盘管理
2. 右键点击要压缩的分区（如D盘）
3. 选择"压缩卷"
4. 输入要压缩的空间大小
5. 点击"压缩"
6. 压缩出的"未分配"空间可以合并到C盘

**适用场景：**
- C盘空间不足
- D盘有足够剩余空间

### 扩展卷

将未分配的空间合并到现有分区。

**操作步骤：**
1. 打开磁盘管理
2. 右键点击要扩展的分区（如C盘）
3. 选择"扩展卷"
4. 按照向导选择要合并的未分配空间
5. 完成扩展

**前提条件：**
- 必须有相邻的未分配空间
- 需要扩展的分区必须是NTFS格式

### 新建简单卷

为未分配的硬盘空间创建新分区。

**操作步骤：**
1. 打开磁盘管理
2. 右键点击"未分配"空间
3. 选择"新建简单卷"
4. 按照向导设置卷大小、驱动器号、文件系统
5. 完成创建

## 安全建议

### 操作前必做

1. **备份重要数据**
   - 将重要文件复制到外接硬盘或云存储
   - 系统镜像备份更佳

2. **确认操作对象**
   - 仔细核对分区盘符（C、D、E...）
   - 确认要操作的是目标分区而非其他

3. **了解操作后果**
   - 格式化会清除分区所有数据
   - 删除分区后数据需要专业工具恢复

### 操作中注意

- 不要在操作过程中断电
- 不要强制关闭程序
- 按照提示一步一步操作

### 操作后检查

- 确认各分区数据完整
- 检查系统启动是否正常
- 验证重要文件可正常访问

## 常见问题

| 问题 | 解决方法 |
|------|----------|
| 压缩卷选项灰色不可点 | 该分区已经是主分区或没有足够连续空间 |
| 扩展卷选项灰色不可点 | 没有相邻的未分配空间 |
| 误删分区 | 立即停止操作，使用 DiskGenius 尝试恢复 |
| 分区丢失 | 使用 MiniTool Partition Wizard 的恢复功能 |

> **提示**：磁盘操作有风险，重要数据请务必提前备份。优先使用 Windows 自带的磁盘管理工具，第三方工具留给高级操作。

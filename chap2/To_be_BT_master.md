# 使用 BT 获取资源

相较于 HTTP/FTP 下载，BT 具有学习资源丰富、用户间互传的特点。

## 认识 BT

**BT（BitTorrent）** 是一种多点共享的文件分发协议。对比传统下载方式：
- HTTP/FTP：服务器是唯一源，下载人数越多速度越慢
- BT：下载者同时互相上传，人越多速度越快

> "下载的人越多，下载的速度越快" —— 这是 BT 的核心优势

### 核心概念

| 概念 | 说明 |
|------|------|
| **种子（.torrent）** | 包含文件信息的元数据文件 |
| **Tracker** | 帮助用户互相发现的服务端 |
| **做种** | 首次分享文件，上传完整数据 |
| **DHT** | 分布式哈希表，去中心化发现用户 |

### 常见下载协议前缀

| 协议 | 说明 |
|------|------|
| `magnet:?xt=urn:btih:` | 磁力链接，最常用 |
| `ed2k://` | 电驴链接 |
| 注意 | 迅雷链接、快车链接**不是**种子链接 |

## BT 下载客户端

### 推荐客户端

| 软件 | 特点 | 平台 |
|------|------|------|
| **qBittorrent** | 开源免费、无广告、功能强大 | Windows/Mac/Linux |
| **比特彗星** | 国产老牌，支持长效做种 | Windows |
| **uTorrent** | 轻量级（不推荐广告较多） | 多平台 |

**为什么不推荐迅雷？**
- 吸血：只下载不上传，影响整体速度
- 广告多：界面充斥广告
- 资源占用高
- 被很多高质量资源站封禁

## 资源获取方法

### 1. 聚合搜索引擎

- 使用英文关键词搜索效果更好

### 2. 专用索引站
- RARBG、1337x、The Pirate Bay 等
- 注意：访问需注意网络和法律风险

### 3. 论坛社区
- 52POJIE（52破解）：软件分享
- 各类资源论坛

### 4. PT 下载站（进阶）
- 会员制，有考核要求
- 适合下载大量学习资源

## BT 下载礼仪

### 基本原则
**人人为我，我为人人**

- 下载完成后继续上传（做种）
- 保持足够的做种时间
- 不要只下载不做种

### 常见问题

| 问题 | 解决方法 |
|------|----------|
| 下载速度为 0 | 检查是否有防火墙拦截 |
| 没有种子 | 等待有人做种或搜索其他来源 |
| 做种没速度 | 确保端口开放、运营商没限速 |
